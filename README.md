## 关于此仓库

这是一个**个人 Web 项目存档仓库**，收录我个人创建的各种技术栈 Web 项目——从学习示例到实际探索，是我开发足迹的持续沉淀。

它不是产品，不具备权威性，也不代表任何组织，仅仅是**我自己的记录**。

## 亮点

- **持续更新** — 每完成一个新项目，这个仓库都会持续归档，不断生长。
- **自由使用** — 基于 MIT 开源协议，你可以自由使用、修改、传播其中的内容。
- **学习与实践** — 记录不同 Web 技术栈下的动手实践轨迹。
